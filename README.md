# 🪪 Profile Card UI Design

A modern, visually engaging **profile card UI** featuring a full-screen video background, social media links, call-to-action button, and interactive analytics counters. Perfect for personal websites, developer portfolios, or "link-in-bio" style pages.

---

## ✨ Features

- 🎬 **Full-screen background video** – autoplays muted for immersive feel
- 👤 **Profile image + name / job title** section
- 🔗 **Social media buttons** (GitHub, LinkedIn, Email) with label hover hints
- 🌐 **Custom website button** – redirects to external URL
- 📊 **Analytics-style counters** (GitHub projects, LinkedIn connections, WhatsApp chats)
- 📱 **Responsive layout** – works on desktop and mobile
- 🎨 **Styled with Box Icons** for crisp social media vectors
